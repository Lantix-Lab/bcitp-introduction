# BrainExpanse

![BrainExpanse 标识](assets/平台LOGO.png)

**Digital Twin Brain based Brain Computer Interface Theoretical Platform**<br>
**数字孪生脑-脑机接口理论平台**

最后修改日期：2026年9月1日 13:02:40

**BrainExpanse** 是面向脑科学与脑机接口理论研究的模块化计算平台，围绕单被试个体化研究场景，组织脑影像预处理、数字孪生脑建模、虚拟物理场仿真、结果映射与可视化能力。

平台的目标不是简单叠加工具，而是构建一条可计算、可复用、可扩展的研究链路：从多模态脑影像出发，建立个体化脑网络模型，模拟电、磁、光等外部刺激在头部组织中的传播，并在进入真实实验前对候选干预方案进行理论推演与比较。

> BrainExpanse 仍在持续开发和完善中。本文档与网站用于公开介绍平台愿景、研究边界和合作方式；算法实现与开发资料不在本公开仓库中发布。

## 平台能力

```text
原始脑影像数据
  -> PRE  脑影像预处理
  -> DTB  数字孪生脑建模
  -> VPF  虚拟物理场仿真
  -> EVA  虚拟干预评估（规划中）
  -> 可视化和结果复核
```

- **个体化脑网络建模**：结合结构连接、功能连接和脑影像衍生指标，构建个体化数字孪生脑。
- **多种刺激方式的物理场仿真**：面向 TMS、tDCS、PBM 等方式，模拟外部物理场在个体头部组织中的分布。
- **脑区尺度映射**：将网格节点或连续空间的物理场结果映射到脑图谱 ROI 尺度，为后续模型输入提供统一表征。
- **模型拟合与参数搜索**：支持脑网络模型仿真、参数扫描与有效连接拟合。
- **研究结果可视化**：提供矩阵、脑表面、ROI、顶点级视图和连接组等结果呈现能力。

## 核心模块

| 模块 | 作用 |
| --- | --- |
| **PRE** | 以 BIDS 组织输入，衔接结构像、功能像和扩散像处理，生成可复用的结构连接、功能连接及相关衍生数据。 |
| **DTB** | 基于 Wilson-Cowan、Dynamic Mean Field 等大尺度脑网络模型，开展个体化脑活动仿真、参数扫描与模型拟合。 |
| **VPF** | 从个体结构 MRI 出发，模拟电、磁、光等外部刺激在头部组织中的传播，并映射到脑区尺度。 |
| **EVA** | 面向候选干预方案筛选、调控参数搜索与健康参考状态趋近分析；目前仍处于能力规划阶段。 |
| **UTL** | 提供脑图谱与脑网格资源、功能连接计算、矩阵和三维脑图可视化等共享能力。 |

## 当前边界

- PRE、DTB、VPF 和 UTL 已形成平台当前的主要能力基础。
- EVA 目前处于规划和接口完善阶段，尚不提供可用于研究或验收的完整评估算法。
- 平台面向研究中的理论推演、方案比较和机制探索，不替代真实实验、临床判断或监管流程。
- 本仓库用于平台公开介绍，不提供安装包、前端服务、任务队列、数据库或远程部署服务。

## Python 软件包

BrainExpanse 的软件能力将通过以下两个 Python 软件包提供：

- `brainexpanse-main`：平台的核心算法包，提供脑影像预处理、数字孪生脑建模、虚拟物理场仿真及通用研究计算能力。
- `brainexpanse-gui`：平台的图形界面包，提供工作流配置、任务管理、进度查看和研究结果可视化能力。
