# BCITP Introduction

脑机接口理论平台的中文静态介绍页。

## 使用方式

本目录是纯静态网站，不需要 Node.js、数据库或服务端程序。将 `index.html`、`styles.css`、`.nojekyll` 和 `assets` 文件夹一起上传至网站目录即可。

本地预览时，请通过本地 HTTP 服务打开，不建议直接双击 `index.html`。

## GitHub Pages

仓库推送后，在 **Settings → Pages** 中选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

保存后等待部署完成即可。
